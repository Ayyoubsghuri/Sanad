قانون رم 81.03 بتنظيم محنة المفوضين القضائيين
مقتضيات عامة
المادة 1
الفوض القضائي مساعد للقضاء يمارس محنة حرة وفقا لأحكام هذا القانون
والنصوص التنظهية المتعلقة بتطبيقه.
المادة 2
تحدث بدوائر المحاكم الابتدائية مكاتب المفوضين القضائيين للقيام بالمهام المنوطة بهم
طبقا لهذا القانون أمام مختلف مك المملكة
المادة 3
تتنافى محنة المفوض القضائي  مارسة أي وظيفة أو مة عمومية ومع كل نشاط
تجاري أو صناعي أو معتبر كذلك بمقتضى القانون. كا تتنافى مع محنة محام أو موثق أو عدل
أو خبير أو ترجان أو وكمل أعبال أو محنة سمسار أو مستشار قانوني أو جبائي، ومع كل
عمل خارج مه يؤدى عنه أجر باستثناء النشاطات العلمية.
